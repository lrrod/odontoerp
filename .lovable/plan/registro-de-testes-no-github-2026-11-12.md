# Registro de testes no GitHub

- Criar a pasta `testes/` na raiz do projeto.
- Copiar o arquivo enviado, sem alterações, para `testes/registro_execucao_testes.md`.
- Adicionar no README.md uma linha na seção de estrutura de pastas: `testes/` — registros de execução do plano de testes.
- A sincronização com o GitHub envia o arquivo automaticamente para o branch atual (main).
